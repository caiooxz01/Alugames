# Alugames

## 📌 Sobre
Projeto utilizado nos cursos de lógica de programação da Alura. A página mostra uma lista de jogos de tabuleiro e permite alugar e devolver cada um pelo botão do jogo.

## ✨ Funcionalidades
- Alugar e devolver jogos, com a imagem e o botão mudando de acordo com o status
- Confirmação antes de devolver um jogo, para evitar devolução acidental
- Contagem de jogos alugados exibida no console a cada alteração

## 🚀 Como usar
Abra o arquivo `index.html` no navegador.
